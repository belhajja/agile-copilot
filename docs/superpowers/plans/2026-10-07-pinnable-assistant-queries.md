# Pinnable Assistant Queries Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The assistant answers board questions through a `query_board` tool whose result the chat
shows with the dashboard's own components and a Pin button. A pinned result is a live dashboard
widget recomputed from synced data.

**Architecture:**
- A declarative board query (zod schema) is run by one pure engine, `runQuery`, in
  `packages/dashboards`. The engine returns the existing `WidgetData`.
- The query becomes the `query` metric of the widget catalog. Storage, pinning and the dashboard
  page therefore reuse the existing widget path.
- The sync adds labels, components, fix versions, priority and epic to `jira_issues`, and the
  dataset carries them.

**Tech Stack:** TypeScript, zod v4, Vitest 5 (`npx vitest run --project <name>`), drizzle-orm and
drizzle-kit, Next.js 16, next-intl, recharts (shadcn chart), Playwright e2e.

**Spec:** `docs/superpowers/specs/2026-10-07-pinnable-assistant-queries-design.md`

## Global Constraints

- Package manager: `npx -y pnpm@10.14.0`. Tests: `npx vitest run --project <name>`, where
  `<name>` is one of `jira`, `sync`, `db`, `metrics`, `dashboards`, `analytics-mcp`, `agent` or
  `web`. Type check: `npx tsc --noEmit -p <package dir>`.
- Biome: only on the files you changed (`npx biome check --write <files>`), never on whole folders.
  On this Windows checkout it rewrites CRLF line endings in files you did not touch.
- Commits:
  - one single-line conventional subject in the repo's style (`feat(dashboards): …`,
    `fix(web): …`), no body, no trailers, no Co-Authored-By, no mention of AI tools;
  - check `git status` before committing; never stage `AGENTS.md` (it is regenerated by tools).
- Do not restart the running dev server (port 3000).
- Docker is needed for `sync`, `dashboards` (pin/store), `analytics-mcp` and `agent` tests
  (Testcontainers).
- Queries are pure data: never build JQL or SQL from a query.
  - The only JQL built is the epic name lookup in Task 1, from keys validated against
    `/^[A-Z][A-Z0-9_]*-\d+$/`.
- Text from Jira (summaries, labels, names) shown in the UI goes through React (escaped), never
  into Markdown.
- Group labels that start with `@` (`@none`, `@other`, `@todo`, `@in_progress`, `@done`) are
  message keys under `dashboards.query.groups`. Every other group label is literal Jira data.
- EN and FR messages for every new UI string; the web `message-keys` test ties the allowlists to
  both files.

**Rulings (deviations from the spec text, decided while planning):**
- **Full resync:** the migration resets `jira_boards.last_full_sync_at` to NULL. The existing rule
  in `run-sync.ts` (`readsCompletely`) then makes each board's next sync a full one, so there is
  no new `needs_full_sync` column. "Fields still syncing" = `BoardDataset.fieldsSynced === false`
  (the board's `lastFullSyncAt` is null).
- **Issue keys are not linked to Jira in v1.** There is no existing link helper, and an OAuth
  connection's `base_url` is an API host. Keys show as text.
- **`includeSubtasks` is not offered.** The dataset excludes sub-tasks, as every metric does.
- **"Resolved" is when the issue last entered a done status** (`doneAt` from `@agile/metrics`),
  not Jira's `resolutiondate`, so it agrees with cycle time.
- **The `epics` filter matches an epic key or an epic name.** Matching is case-insensitive.
- **Caps:**
  - a second dimension keeps at most 8 series plus Other;
  - the sprint dimension keeps the 20 most recent sprints;
  - a 2-dimension result is not capped further.
- **A KPI on count or points returns 0 (not empty) when nothing matches.** Grouped and list
  results return `{ kind: 'empty', reason: 'no_match' }`.

## Review Focus

1. **A board whose site has no Epic Link field, or whose issues have a non-epic parent:** the epic
   stays null and the sync never fails. Task 1 tests this.
2. **Names typed with a different case or extra spaces** (`"bug"`, `" In Progress "`) still match.
   Task 4 tests this.
3. **A points query on a board without estimates** counts issues and says so. Task 5 tests this.
4. **A stored query widget that no longer validates** (a future schema change) renders an
   "unavailable" card and never breaks the page. Task 6 tests this.
5. **Grouping by sprint on a board with many sprints** (a real board has 79) shows the 20 most
   recent, with a note. Task 5 tests this.

```ts
export async function saveEpicNames(
```

```ts
import type { JiraDataSource } from '@agile/jira';

const ISSUE_KEY = /^[A-Z][A-Z0-9_]*-\d+$/;
const CHUNK = 50;

/**
 * Epic summaries by key, for Data Center's Epic Link (which holds only the key). Keys are checked
 * before they reach JQL. A failing search (an epic deleted or hidden from this account) only
 * leaves its names out: the keys are stored anyway.
 */
export async function epicNames(
  source: Pick<JiraDataSource, 'searchIssues'>,
  keys: readonly string[],
): Promise<Map<string, string>> {
  const valid = [...new Set(keys)].filter((k) => ISSUE_KEY.test(k));
  const names = new Map<string, string>();
  for (let i = 0; i < valid.length; i += CHUNK) {
    const chunk = valid.slice(i, i + CHUNK);
    try {
      for await (const page of source.searchIssues(`key in (${chunk.join(',')})`, ['summary'])) {
        for (const raw of page) {
          const summary = (raw.fields as { summary?: unknown }).summary;
          if (typeof summary === 'string' && summary.trim() !== '') names.set(raw.key, summary.trim());
        }
      }
    } catch {
      // Cosmetic: the issues keep their epic key without a name until the next sync.
    }
  }
  return names;
}
```

```ts
import { z } from 'zod';

// A board query: data the assistant writes and the dashboard re-runs on synced data. Every time
// reference is relative to "now", so a pinned query stays live.

export const DIMENSIONS = [
  'type',
  'status',
  'statusCategory',
  'assignee',
  'label',
  'epic',
  'priority',
  'component',
  'fixVersion',
  'sprint',
  'createdWeek',
  'createdMonth',
  'resolvedWeek',
  'resolvedMonth',
] as const;
export const MEASURES = ['count', 'points', 'avg_cycle_time', 'p85_cycle_time', 'avg_age'] as const;
export const DISPLAYS = ['kpi', 'table', 'bar', 'stacked_bar', 'line', 'pie', 'list'] as const;
export const COLUMNS = [
  'key',
  'summary',
  'type',
  'status',
  'assignee',
  'points',
  'priority',
  'epic',
  'labels',
  'created',
  'resolved',
  'age',
] as const;

export type Dimension = (typeof DIMENSIONS)[number];
export type Measure = (typeof MEASURES)[number];
export type Display = (typeof DISPLAYS)[number];
export type Column = (typeof COLUMNS)[number];

export const TIME_DIMENSIONS: ReadonlySet<Dimension> = new Set<Dimension>([
  'createdWeek',
  'createdMonth',
  'resolvedWeek',
  'resolvedMonth',
]);

/** Largest serialized query (it is stored in the dashboard row and sent to the model). */
export const MAX_QUERY_BYTES = 4096;

const text = (max: number) =>
  z
    .string()
    .trim()
    .min(1)
    .max(max)
    .refine((v) => !/[\p{Cc}‪-‮⁦-⁩]/u.test(v), 'control characters');
const names = z.array(text(100)).min(1).max(10);

const sprintRef = z.union([
  z.literal('active'),
  z.literal('last_closed'),
  z.strictObject({ lastClosed: z.number().int().min(1).max(20) }),
  z.strictObject({ id: z.string().min(1).max(64) }),
]);
const window = z.union([
  z.strictObject({ lastDays: z.number().int().min(1).max(730) }),
  z.strictObject({ sinceSprintsAgo: z.number().int().min(1).max(20) }),
]);

const filter = z.strictObject({
  types: names.optional(),
  statuses: names.optional(),
  statusCategory: z.array(z.enum(['todo', 'in_progress', 'done'])).min(1).max(3).optional(),
  /** Display names; null = unassigned. */
  assignees: z.array(text(100).nullable()).min(1).max(10).optional(),
  labels: names.optional(),
  /** Epic keys or names. */
  epics: names.optional(),
  priorities: names.optional(),
  components: names.optional(),
  fixVersions: names.optional(),
  sprints: z.array(sprintRef).min(1).max(10).optional(),
  created: window.optional(),
  resolved: window.optional(),
});

const list = z.strictObject({
  columns: z.array(z.enum(COLUMNS)).min(1).max(8),
  sort: z
    .strictObject({ by: z.enum(COLUMNS), dir: z.enum(['asc', 'desc']).default('asc') })
    .optional(),
  limit: z.number().int().min(1).max(50).default(20),
});

export const boardQuerySchema = z
  .strictObject({
    title: text(80),
    filter: filter.optional(),
    groupBy: z.array(z.enum(DIMENSIONS)).min(1).max(2).optional(),
    measure: z.enum(MEASURES).default('count'),
    display: z.enum(DISPLAYS),
    list: list.optional(),
    /** Keep the N largest groups; the rest becomes "Other". Categories only. */
    top: z.number().int().min(1).max(20).optional(),
  })
  .superRefine((q, ctx) => {
    const refuse = (path: (string | number)[], message: string) =>
      ctx.addIssue({ code: 'custom', path, message });
    const dims = q.groupBy ?? [];
    const [first] = dims;
    if (new Set(dims).size !== dims.length) refuse(['groupBy'], 'the same dimension twice');
    switch (q.display) {
      case 'kpi':
        if (dims.length > 0) refuse(['groupBy'], 'kpi takes no groupBy');
        break;
      case 'list':
        if (dims.length > 0) refuse(['groupBy'], 'list takes no groupBy');
        if (!q.list) refuse(['list'], 'list needs list.columns');
        break;
      case 'table':
        if (dims.length === 0) refuse(['groupBy'], 'table needs groupBy (use display list for issues)');
        break;
      case 'stacked_bar':
        if (dims.length !== 2) refuse(['groupBy'], 'stacked_bar needs 2 dimensions');
        break;
      default:
        if (dims.length !== 1) refuse(['groupBy'], `${q.display} needs 1 dimension`);
        else if (
          q.display === 'line' &&
          first !== undefined &&
          !TIME_DIMENSIONS.has(first) &&
          first !== 'sprint'
        ) {
          refuse(['groupBy'], 'line needs a week, month or sprint dimension');
        }
    }
    if (q.list && q.display !== 'list') refuse(['list'], 'list is only for display list');
    if (q.display === 'pie' && q.measure !== 'count' && q.measure !== 'points') {
      refuse(['measure'], 'pie needs count or points');
    }
    if (q.top !== undefined && first !== undefined && (TIME_DIMENSIONS.has(first) || first === 'sprint')) {
      refuse(['top'], 'top is for categories');
    }
    if (JSON.stringify(q).length > MAX_QUERY_BYTES) {
      refuse([], `query larger than ${MAX_QUERY_BYTES} bytes`);
    }
  });

export type BoardQuery = z.output<typeof boardQuerySchema>;
export type QueryFilter = NonNullable<BoardQuery['filter']>;
export type SprintRef = NonNullable<QueryFilter['sprints']>[number];
export type QueryWindow = NonNullable<QueryFilter['created']>;
```

```ts
import {
  type BoardDataset,
  currentCategory,
  DAY,
  doneAt,
  type MetricIssue,
  type MetricSprint,
} from '@agile/metrics';
import { bySprintDate } from '../sprint-scope';
import type { BoardQuery, QueryFilter, QueryWindow, SprintRef } from './schema';

const lower = (s: string) => s.trim().toLowerCase();

/** Every sprint each issue was ever in, chronological and distinct. */
export function sprintsByIssue(ds: BoardDataset): Map<string, MetricSprint[]> {
  const map = new Map<string, MetricSprint[]>();
  for (const sprint of [...ds.sprints].sort(bySprintDate)) {
    for (const m of sprint.members) {
      const list = map.get(m.issueId) ?? [];
      if (!list.includes(sprint)) list.push(sprint);
      map.set(m.issueId, list);
    }
  }
  return map;
}

/** Closed sprints, the most recently completed first. */
function closedSprints(ds: BoardDataset): (MetricSprint & { completeAt: Date })[] {
  return ds.sprints
    .filter((s): s is MetricSprint & { completeAt: Date } => s.state === 'closed' && s.completeAt !== null)
    .sort((a, b) => b.completeAt.getTime() - a.completeAt.getTime());
}

/** The board's sprints a query names. Unknown ids resolve to nothing. */
export function resolveSprints(ds: BoardDataset, refs: readonly SprintRef[]): MetricSprint[] {
  const closed = closedSprints(ds);
  const found = new Map<string, MetricSprint>();
  for (const ref of refs) {
    const picked =
      ref === 'active'
        ? ds.sprints.filter((s) => s.state === 'active')
        : ref === 'last_closed'
          ? closed.slice(0, 1)
          : 'lastClosed' in ref
            ? closed.slice(0, ref.lastClosed)
            : ds.sprints.filter((s) => s.id === ref.id);
    for (const s of picked) found.set(s.id, s);
  }
  return [...found.values()];
}

/**
 * Where a relative window starts: `lastDays` back from now, or the start of the n-th most recently
 * started sprint (the oldest one when there are fewer; now, so an empty window, when none).
 */
export function windowStart(ds: BoardDataset, w: QueryWindow, now: Date): Date {
  if ('lastDays' in w) return new Date(now.getTime() - w.lastDays * DAY);
  const started = ds.sprints
    .filter((s): s is MetricSprint & { startAt: Date } => s.startAt !== null && s.startAt.getTime() <= now.getTime())
    .sort((a, b) => b.startAt.getTime() - a.startAt.getTime());
  return (started[w.sinceSprintsAgo - 1] ?? started.at(-1))?.startAt ?? now;
}

const within = (at: Date | null, from: Date, now: Date) =>
  at !== null && at.getTime() > from.getTime() && at.getTime() <= now.getTime();

/**
 * The issues a query's filter keeps. Filters combine with AND, values in one filter with OR; names
 * match case-insensitively. Without its own `sprints`, the query follows the dashboard's sprint
 * selection (`scope`): issues that were in one of those sprints.
 */
export function selectIssues(
  ds: BoardDataset,
  query: BoardQuery,
  opts: {
    now: Date;
    scope?: readonly MetricSprint[];
    sprintsOf: Map<string, MetricSprint[]>;
  },
): MetricIssue[] {
  const { now } = opts;
  const f: QueryFilter = query.filter ?? {};
  const set = (values: readonly string[] | undefined) => (values ? new Set(values.map(lower)) : null);
  const types = set(f.types);
  const statuses = set(f.statuses);
  const labels = set(f.labels);
  const epics = set(f.epics);
  const priorities = set(f.priorities);
  const components = set(f.components);
  const fixVersions = set(f.fixVersions);
  const categories = f.statusCategory ? new Set<string>(f.statusCategory) : null;
  const assignees = f.assignees
    ? new Set(f.assignees.map((a) => (a === null ? null : lower(a))))
    : null;
  const sprints = f.sprints
    ? resolveSprints(ds, f.sprints)
    : opts.scope && opts.scope.length > 0
      ? opts.scope
      : null;
  const sprintIds = sprints ? new Set(sprints.map((s) => s.id)) : null;
  const created = f.created ? windowStart(ds, f.created, now) : null;
  const resolved = f.resolved ? windowStart(ds, f.resolved, now) : null;

  const has = (wanted: Set<string> | null, value: string | null | undefined) =>
    !wanted || (value != null && wanted.has(lower(value)));
  const hasAny = (wanted: Set<string> | null, values: readonly string[] | undefined) =>
    !wanted || (values ?? []).some((v) => wanted.has(lower(v)));

  return ds.issues.filter(
    (i) =>
      has(types, i.type) &&
      has(statuses, i.status) &&
      (!categories || categories.has(currentCategory(i))) &&
      (!assignees || assignees.has(i.assignee === null ? null : lower(i.assignee))) &&
      hasAny(labels, i.labels) &&
      hasAny(components, i.components) &&
      hasAny(fixVersions, i.fixVersions) &&
      has(priorities, i.priority) &&
      (!epics || has(epics, i.epicKey) || has(epics, i.epicName)) &&
      (!sprintIds || (opts.sprintsOf.get(i.id) ?? []).some((s) => sprintIds.has(s.id))) &&
      (!created || within(i.createdAt, created, now)) &&
      (!resolved || within(doneAt(i), resolved, now)),
  );
}
```

```ts
import { cycleStart, DAY, doneAt, type MetricIssue, percentile } from '@agile/metrics';
import type { Measure } from './schema';

const round = (value: number, digits: number) => {
  const f = 10 ** digits;
  return Math.round(value * f) / f;
};
const mean = (values: readonly number[]) =>
  values.length === 0 ? null : round(values.reduce((a, b) => a + b, 0) / values.length, 1);

/** Days from first "in progress" to done, for issues that are done now. */
const cycleDays = (issues: readonly MetricIssue[]) =>
  issues.flatMap((i) => {
    const start = cycleStart(i);
    const done = doneAt(i);
    return start && done ? [(done.getTime() - start.getTime()) / DAY] : [];
  });

/**
 * One number for a set of issues. Points are current estimates; cycle time uses the same
 * definition as the cycle_time metric; age is for open issues. null when nothing qualifies.
 */
export function measureOf(issues: readonly MetricIssue[], measure: Measure, now: Date): number | null {
  switch (measure) {
    case 'count':
      return issues.length;
    case 'points':
      return round(
        issues.reduce((total, i) => total + (i.estimate ?? 0), 0),
        2,
      );
    case 'avg_cycle_time':
      return mean(cycleDays(issues));
    case 'p85_cycle_time': {
      const p = percentile(cycleDays(issues), 85);
      return p === null ? null : round(p, 1);
    }
    case 'avg_age':
      return mean(
        issues.filter((i) => doneAt(i) === null).map((i) => (now.getTime() - i.createdAt.getTime()) / DAY),
      );
  }
}
```

```ts
import {
  addDays,
  currentCategory,
  doneAt,
  isoDay,
  type MetricIssue,
  type MetricSprint,
  startOfUtcWeek,
} from '@agile/metrics';
import type { Dimension } from './schema';

/** Group tokens (message keys under dashboards.query.groups). */
export const NONE = '@none';
export const OTHER = '@other';

/** Dimensions where an issue can fall in several groups. */
export const MULTI_VALUED: ReadonlySet<Dimension> = new Set<Dimension>([
  'label',
  'component',
  'fixVersion',
  'sprint',
]);

export interface GroupContext {
  sprintsOf: Map<string, MetricSprint[]>;
  /** With a sprint filter or selection, sprint groups are limited to those sprints. */
  allowedSprints: ReadonlySet<string> | null;
}

const month = (d: Date) => d.toISOString().slice(0, 7);
const valuesOrNone = (values: readonly string[] | undefined) =>
  values && values.length > 0 ? [...new Set(values)] : [NONE];

/** The groups an issue falls in. [] leaves it out (a time dimension without its date). */
export function groupsOf(issue: MetricIssue, dim: Dimension, ctx: GroupContext): string[] {
  switch (dim) {
    case 'type':
      return [issue.type];
    case 'status':
      return [issue.status ? issue.status : NONE];
    case 'statusCategory':
      return [`@${currentCategory(issue)}`];
    case 'assignee':
      return [issue.assignee ?? NONE];
    case 'priority':
      return [issue.priority ?? NONE];
    case 'epic':
      return [
        issue.epicKey ? (issue.epicName ? `${issue.epicKey} · ${issue.epicName}` : issue.epicKey) : NONE,
      ];
    case 'label':
      return valuesOrNone(issue.labels);
    case 'component':
      return valuesOrNone(issue.components);
    case 'fixVersion':
      return valuesOrNone(issue.fixVersions);
    case 'sprint':
      return valuesOrNone(
        (ctx.sprintsOf.get(issue.id) ?? [])
          .filter((s) => !ctx.allowedSprints || ctx.allowedSprints.has(s.id))
          .map((s) => s.name),
      );
    case 'createdWeek':
      return [isoDay(startOfUtcWeek(issue.createdAt))];
    case 'createdMonth':
      return [month(issue.createdAt)];
    case 'resolvedWeek': {
      const at = doneAt(issue);
      return at ? [isoDay(startOfUtcWeek(at))] : [];
    }
    case 'resolvedMonth': {
      const at = doneAt(issue);
      return at ? [month(at)] : [];
    }
  }
}

/** Issues per group, groups in first-seen order. */
export function bucketIssues(
  issues: readonly MetricIssue[],
  dim: Dimension,
  ctx: GroupContext,
): Map<string, MetricIssue[]> {
  const buckets = new Map<string, MetricIssue[]>();
  for (const issue of issues) {
    for (const key of groupsOf(issue, dim, ctx)) {
      const list = buckets.get(key);
      if (list) list.push(issue);
      else buckets.set(key, [issue]);
    }
  }
  return buckets;
}

/** Every week (yyyy-mm-dd, Monday) or month (yyyy-mm) key from `from` to `to`, inclusive. */
export function timeKeys(dim: Dimension, from: Date, to: Date): string[] {
  const keys: string[] = [];
  if (dim.endsWith('Week')) {
    const last = startOfUtcWeek(to).getTime();
    for (let w = startOfUtcWeek(from); w.getTime() <= last; w = addDays(w, 7)) keys.push(isoDay(w));
    return keys;
  }
  let y = from.getUTCFullYear();
  let m = from.getUTCMonth();
  const end = to.getUTCFullYear() * 12 + to.getUTCMonth();
  while (y * 12 + m <= end) {
    keys.push(`${y}-${String(m + 1).padStart(2, '0')}`);
    m += 1;
    if (m === 12) {
      m = 0;
      y += 1;
    }
  }
  return keys;
}
```

```ts
import {
  type BoardDataset,
  DAY,
  doneAt,
  isoDay,
  type MetricIssue,
  type MetricSprint,
} from '@agile/metrics';
import { bySprintDate } from '../sprint-scope';
import type { KpiFormat, WidgetData, WidgetNote } from '../widget-data';
import { bucketIssues, type GroupContext, MULTI_VALUED, NONE, OTHER, timeKeys } from './group';
import { measureOf } from './measure';
import { type BoardQuery, type Column, type Dimension, type Measure, TIME_DIMENSIONS } from './schema';
import { resolveSprints, selectIssues, sprintsByIssue, windowStart } from './select';

/** Most category groups shown (the rest folds into Other). */
const MAX_GROUPS = 20;
/** Most series of a second dimension (the rest folds into Other). */
const MAX_SERIES = 8;

const NEW_FIELD_FILTERS = ['labels', 'epics', 'priorities', 'components', 'fixVersions'] as const;
const NEW_FIELD_DIMENSIONS: ReadonlySet<Dimension> = new Set<Dimension>([
  'label',
  'epic',
  'priority',
  'component',
  'fixVersion',
]);
const NEW_FIELD_COLUMNS: ReadonlySet<Column> = new Set<Column>(['priority', 'epic', 'labels']);

const COLUMN_TYPES: Record<Column, 'text' | 'number' | 'days' | 'date'> = {
  key: 'text',
  summary: 'text',
  type: 'text',
  status: 'text',
  assignee: 'text',
  points: 'number',
  priority: 'text',
  epic: 'text',
  labels: 'text',
  created: 'date',
  resolved: 'date',
  age: 'days',
};

interface Group {
  label: string;
  issues: MetricIssue[];
}

interface Ctx extends GroupContext {
  ds: BoardDataset;
  query: BoardQuery;
  measure: Measure;
  now: Date;
  notes: WidgetNote[];
}

const formatOf = (m: Measure): KpiFormat => (m === 'count' ? 'issues' : m === 'points' ? 'points' : 'days');
const valueType = (m: Measure): 'number' | 'days' => (m === 'count' || m === 'points' ? 'number' : 'days');

function usesNewFields(q: BoardQuery): boolean {
  return (
    NEW_FIELD_FILTERS.some((k) => q.filter?.[k] !== undefined) ||
    (q.groupBy ?? []).some((d) => NEW_FIELD_DIMENSIONS.has(d)) ||
    (q.list?.columns ?? []).some((c) => NEW_FIELD_COLUMNS.has(c))
  );
}

/** The groups' issues, each once (multi-valued groups share issues). */
const unique = (groups: readonly Group[]): MetricIssue[] => [
  ...new Map(groups.flatMap((g) => g.issues.map((i) => [i.id, i] as const))).values(),
];

const byLabel = (a: Group, b: Group) => (a.label < b.label ? -1 : a.label > b.label ? 1 : 0);

/** Groups of one dimension, ordered and capped. */
function groupsFor(
  issues: readonly MetricIssue[],
  dim: Dimension,
  ctx: Ctx,
  limits: { max: number; top?: number },
): Group[] {
  const buckets = bucketIssues(issues, dim, ctx);
  if (TIME_DIMENSIONS.has(dim)) {
    const created = dim.startsWith('created');
    const window = created ? ctx.query.filter?.created : ctx.query.filter?.resolved;
    const dates = issues.flatMap((i) => {
      const at = created ? i.createdAt : doneAt(i);
      return at ? [at.getTime()] : [];
    });
    if (!window && dates.length === 0) return [];
    const from = window ? windowStart(ctx.ds, window, ctx.now) : new Date(Math.min(...dates));
    const to = window ? ctx.now : new Date(Math.max(...dates));
    return timeKeys(dim, from, to).map((label) => ({ label, issues: buckets.get(label) ?? [] }));
  }
  const groups = [...buckets].map(([label, list]) => ({ label, issues: list }));
  if (dim === 'sprint') {
    const order = [...ctx.ds.sprints].sort(bySprintDate).map((s) => s.name);
    const rank = (g: Group) => (g.label === NONE ? Number.POSITIVE_INFINITY : order.indexOf(g.label));
    const named = groups.filter((g) => g.label !== NONE).sort((a, b) => rank(a) - rank(b));
    const none = groups.filter((g) => g.label === NONE);
    if (named.length <= MAX_GROUPS) return [...named, ...none];
    ctx.notes.push({ key: 'capped', values: { shown: MAX_GROUPS, total: named.length } });
    return [...named.slice(-MAX_GROUPS), ...none];
  }
  const value = new Map(groups.map((g) => [g, measureOf(g.issues, ctx.measure, ctx.now)]));
  const sorted = groups.sort((a, b) => {
    const va = value.get(a) ?? null;
    const vb = value.get(b) ?? null;
    if (va === vb) return byLabel(a, b);
    if (va === null) return 1;
    if (vb === null) return -1;
    return vb - va;
  });
  const keep = limits.top ?? limits.max;
  if (sorted.length <= keep) return sorted;
  if (limits.top === undefined) {
    ctx.notes.push({ key: 'capped', values: { shown: keep, total: sorted.length } });
  }
  return [...sorted.slice(0, keep), { label: OTHER, issues: unique(sorted.slice(keep)) }];
}

function cellOf(i: MetricIssue, column: Column, now: Date): string | number | null {
  switch (column) {
    case 'key':
      return i.key;
    case 'summary':
      return i.summary;
    case 'type':
      return i.type;
    case 'status':
      return i.status || null;
    case 'assignee':
      return i.assignee;
    case 'points':
      return i.estimate;
    case 'priority':
      return i.priority ?? null;
    case 'epic':
      return i.epicName ?? i.epicKey ?? null;
    case 'labels':
      return i.labels && i.labels.length > 0 ? i.labels.join(', ') : null;
    case 'created':
      return isoDay(i.createdAt);
    case 'resolved': {
      const at = doneAt(i);
      return at ? isoDay(at) : null;
    }
    case 'age':
      return doneAt(i) ? null : Math.round(((now.getTime() - i.createdAt.getTime()) / DAY) * 10) / 10;
  }
}

/** Empty values last, whatever the direction; numbers numerically; text with numeric parts. */
function compareCells(a: string | number | null, b: string | number | null, dir: 1 | -1): number {
  if (a === b) return 0;
  if (a === null) return 1;
  if (b === null) return -1;
  if (typeof a === 'number' && typeof b === 'number') return dir * (a - b);
  return dir * String(a).localeCompare(String(b), 'en', { numeric: true });
}

function listOf(issues: readonly MetricIssue[], query: BoardQuery, ctx: Ctx): WidgetData {
  const list = query.list;
  if (!list) return { kind: 'empty', reason: 'no_match' };
  const by = list.sort?.by ?? 'key';
  const dir = list.sort?.dir === 'desc' ? -1 : 1;
  const sorted = [...issues].sort((a, b) =>
    compareCells(cellOf(a, by, ctx.now), cellOf(b, by, ctx.now), dir),
  );
  if (sorted.length > list.limit) {
    ctx.notes.push({ key: 'capped', values: { shown: list.limit, total: sorted.length } });
  }
  return {
    kind: 'table',
    columns: list.columns.map((c) => ({ key: c, type: COLUMN_TYPES[c] })),
    rows: sorted.slice(0, list.limit).map((i) => list.columns.map((c) => cellOf(i, c, ctx.now))),
  };
}

/**
 * Runs a board query on synced data. Pure and deterministic for a given `now`. Without its own
 * `sprints` filter the query follows the dashboard's sprint selection (`scope`); with one it is
 * computed as is and flagged `unfiltered` when a selection is active.
 */
export function runQuery(
  ds: BoardDataset,
  query: BoardQuery,
  opts: { now: Date; scope?: readonly MetricSprint[] },
): WidgetData {
  const { now } = opts;
  const sprintsOf = sprintsByIssue(ds);
  const ownSprints = query.filter?.sprints !== undefined;
  const scoped = (opts.scope?.length ?? 0) > 0;
  const issues = selectIssues(ds, query, { now, scope: ownSprints ? undefined : opts.scope, sprintsOf });
  const notes: WidgetNote[] = [];
  const measure: Measure = query.measure === 'points' && !ds.hasEstimates ? 'count' : query.measure;
  if (measure !== query.measure) notes.push({ key: 'pointsAsCount' });
  if (ds.fieldsSynced === false && usesNewFields(query)) notes.push({ key: 'fieldsSyncing' });
  const dims = query.groupBy ?? [];
  if (dims.some((d) => MULTI_VALUED.has(d))) notes.push({ key: 'multiValued' });
  const finish = (data: WidgetData): WidgetData => ({
    ...data,
    ...(notes.length > 0 ? { notes } : {}),
    ...(ownSprints && scoped ? { unfiltered: true as const } : {}),
  });

  if (query.display === 'kpi') {
    return finish({ kind: 'kpi', value: measureOf(issues, measure, now), format: formatOf(measure) });
  }
  const sprintLimit = ownSprints
    ? resolveSprints(ds, query.filter?.sprints ?? [])
    : scoped
      ? opts.scope
      : undefined;
  const ctx: Ctx = {
    ds,
    query,
    measure,
    now,
    notes,
    sprintsOf,
    allowedSprints: sprintLimit ? new Set(sprintLimit.map((s) => s.id)) : null,
  };
  if (issues.length === 0) return finish({ kind: 'empty', reason: 'no_match' });
  if (query.display === 'list') return finish(listOf(issues, query, ctx));

  const [first, second] = dims;
  if (!first) return finish({ kind: 'empty', reason: 'no_match' });
  const rows = groupsFor(issues, first, ctx, { max: MAX_GROUPS, top: query.top });
  if (rows.length === 0) return finish({ kind: 'empty', reason: 'no_match' });

  if (!second) {
    const values = rows.map((g) => measureOf(g.issues, measure, now));
    if (query.display === 'table') {
      return finish({
        kind: 'table',
        columns: [
          { key: first, type: 'text' },
          { key: measure, type: valueType(measure) },
        ],
        rows: rows.map((g, i) => [g.label, values[i] ?? null]),
      });
    }
    return finish({
      kind: 'series',
      chart: query.display === 'pie' ? 'pie' : query.display === 'line' ? 'line' : 'bar',
      x: first,
      series: [{ key: measure }],
      rows: rows.map((g, i) => ({ [first]: g.label, [measure]: values[i] ?? null })),
    });
  }

  const columns = groupsFor(issues, second, ctx, { max: MAX_SERIES });
  const cell = (row: Group, column: Group) => {
    const ids = new Set(column.issues.map((i) => i.id));
    return measureOf(
      row.issues.filter((i) => ids.has(i.id)),
      measure,
      now,
    );
  };
  if (query.display === 'table') {
    return finish({
      kind: 'table',
      columns: [
        { key: first, type: 'text' },
        ...columns.map((c, i) => ({ key: `s${i}`, type: valueType(measure), label: c.label })),
      ],
      rows: rows.map((r) => [r.label, ...columns.map((c) => cell(r, c))]),
    });
  }
  return finish({
    kind: 'series',
    chart: 'bar',
    x: first,
    series: columns.map((c, i) => ({ key: `s${i}`, label: c.label, stacked: true })),
    rows: rows.map((r) => ({
      [first]: r.label,
      ...Object.fromEntries(columns.map((c, i) => [`s${i}`, cell(r, c)])),
    })),
  });
}
```

```tsx
import type { KpiFormat, WidgetData } from '@agile/dashboards';
import { useFormatter, useTranslations } from 'next-intl';
import { allowedCode } from '@/lib/error-code';
import { useGroupLabel } from './group-label';
import { DASHBOARD_EMPTY_REASONS, DASHBOARD_HINTS, DASHBOARD_NOTES, DASHBOARD_SERIES } from './message-keys';
import { WidgetChart } from './widget-chart';
import { WidgetTable } from './widget-table';

/** A KPI value in its unit ("19 pts", "95 %", "3.5 days"); — when there is none. */
export function useKpiText(): (format: KpiFormat, value: number | null) => string {
  const t = useTranslations('dashboards');
  const format = useFormatter();
  return (kpiFormat, v) => {
    if (v === null) return '—';
    if (kpiFormat === 'percent') return format.number(v, { style: 'percent', maximumFractionDigits: 0 });
    return t(`units.${kpiFormat}`, { count: v, value: format.number(v, { maximumFractionDigits: 1 }) });
  };
}

/** A widget's footnotes (query notes), translated; nothing when it has none. */
export function WidgetNotes({ data }: { data: WidgetData }) {
  const t = useTranslations('dashboards.query.notes');
  const notes = (data.notes ?? []).flatMap((n) => {
    const key = allowedCode(n.key, DASHBOARD_NOTES);
    return key ? [{ key, values: n.values ?? {} }] : [];
  });
  if (notes.length === 0) return null;
  return (
    <ul className="grid gap-0.5 text-xs text-muted-foreground" data-notes>
      {notes.map((n) => (
        <li key={n.key}>{t(n.key, n.values)}</li>
      ))}
    </ul>
  );
}

/** What a widget shows, without its card: chart, table, KPI value or why there is nothing. */
export function WidgetBody({ data }: { data: WidgetData }) {
  const t = useTranslations('dashboards');
  const kpiText = useKpiText();
  const groupLabel = useGroupLabel();
  const seriesLabel = (key: string) => {
    const known = allowedCode(key, DASHBOARD_SERIES);
    return known ? t(`series.${known}`) : key;
  };
  switch (data.kind) {
    case 'series':
      return (
        <WidgetChart
          data={data}
          labels={Object.fromEntries(
            data.series.map((s) => [s.key, s.label ? groupLabel(s.label) : seriesLabel(s.key)]),
          )}
        />
      );
    case 'table':
      return <WidgetTable data={data} />;
    case 'kpi': {
      const hintKey = allowedCode(data.hint?.key, DASHBOARD_HINTS);
      return (
        <div className="grid gap-1">
          <p className="text-3xl font-semibold tabular-nums">{kpiText(data.format, data.value)}</p>
          {data.hint && hintKey && (
            <p className="text-sm text-muted-foreground">{t(`hints.${hintKey}`, data.hint.values ?? {})}</p>
          )}
        </div>
      );
    }
```

```ts
import type { WidgetData } from '@agile/dashboards';

const boardRef = z.object({ id: z.uuid(), name: z.string().max(300) });
const widgetData = z.looseObject({ kind: z.enum(['kpi', 'series', 'table', 'empty']) });
const queryResult = z.object({
  board: boardRef,
  query: z.looseObject({ title: z.string(), display: z.string() }),
  data: widgetData,
  computedAt: z.string(),
});
const metricResult = z.object({
  board: boardRef,
  metric: z.string(),
  chart: z.string(),
  params: z.record(z.string(), z.unknown()),
  data: widgetData,
  computedAt: z.string().optional(),
});

/** A tool result the chat can show as a widget and pin: what it shows and the widget to store. */
export interface PinnableResult {
  board: { id: string; name: string };
  computedAt: string | null;
  data: WidgetData;
  widget: { metric: string; chart: string; title?: string; params: Record<string, unknown> };
}

/**
 * A `query_board` or `get_metric` result, or undefined for anything else. The widget is
 * re-validated by the server when pinned; here the shape only has to be renderable.
 */
export function pinnableResultOf(toolName: string, output: unknown): PinnableResult | undefined {
  if (typeof output !== 'string') return undefined;
  const value = parseUntrustedData(output)?.value;
  if (toolName === 'query_board') {
    const r = queryResult.safeParse(value);
    if (!r.success) return undefined;
    return {
      board: r.data.board,
      computedAt: r.data.computedAt,
      data: r.data.data as WidgetData,
      widget: { metric: 'query', chart: r.data.query.display, title: r.data.query.title, params: r.data.query },
    };
  }
  if (toolName === 'get_metric') {
    const r = metricResult.safeParse(value);
    if (!r.success) return undefined;
    return {
      board: r.data.board,
      computedAt: r.data.computedAt ?? null,
      data: r.data.data as WidgetData,
      widget: { metric: r.data.metric, chart: r.data.chart, params: r.data.params },
    };
  }
  return undefined;
}
```

```ts
export type PinResultActionResult =
  | { ok: true; boardId: string }
  | { ok: false; code: 'invalid_widget' | 'unknown_board' | 'dashboard_full' | 'unknown' };

const pinInput = z.object({ boardId: z.uuid(), widget: z.record(z.string(), z.unknown()) });

/** Pins a chat result to the user's "Pinned" dashboard of its board (same checks as the assistant's). */
export async function pinResultAction(input: { boardId: string; widget: unknown }): Promise<PinResultActionResult> {
  const actor = await requireActor();
  const parsed = pinInput.safeParse(input);
  if (!parsed.success) return { ok: false, code: 'invalid_widget' };
  try {
    const result = await pinWidget(
      services().db,
      { orgId: actor.orgId, userId: actor.userId },
      { boardId: parsed.data.boardId, widget: parsed.data.widget, via: 'user' },
    );
    if (!result.ok) return { ok: false, code: result.code };
    revalidatePath(`/boards/${parsed.data.boardId}`);
    return { ok: true, boardId: parsed.data.boardId };
  } catch {
    return { ok: false, code: 'unknown' };
  }
}
```
